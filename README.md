# 📊 Employee Attendance Analysis (Excel Project)

## 📌 Project Overview  
This project analyzes **employee attendance data** using Microsoft Excel. It includes **data validation, automated calculations, and visualizations** to track employee attendance trends efficiently.  

## 📂 Key Features  
- **Data Entry & Validation:**  
  - Drop-down lists for attendance status (**Present, Late, Absent**).  
- **Automated Calculations:**  
  - Total **absent days** per employee.  
  - Total **working hours** per department.  
- **Data Visualization:**  
  - **Bar chart** for attendance trends.  
  - **Pivot table** for department-wise working hours.  

## 🛠 Tools Used  
✅ Microsoft Excel  
✅ Pivot Tables  
✅ Data Validation  
✅ Conditional Formatting  
✅ Charts & Visualizations  

## 📥 Dataset  
The dataset was created based on **realistic employee attendance scenarios** for learning and practice purposes.  

## 🔗 How to Use  
1. **Download the Excel file (.xlsx) from this repository.**  
2. **Open in Microsoft Excel or Google Sheets.**  
3. **Explore attendance trends using charts and pivot tables.**
